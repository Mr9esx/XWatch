# 推送排版规范

当 `xwatch check` 返回新推文需要推送时，**必须严格**按以下规则排版。

## 排版规则

1. **按标签分区**：每个标签（如黄金、影响力）作为一个独立区块
2. **区块内按用户分组**：同一用户的推文归在一起
3. **用户内按时间倒序**：最新的推文排在前面
4. **非中文推文翻译为中文**，只展示翻译内容；中文推文直接展示原文
5. **每条推文必须用 `>` 开头（markdown 引用块）**。这是强制要求，不可省略。没有 `>` 的推文格式视为错误。

## 推文格式

每条推文**必须**以 `> ` 开头，完整格式为：

```
> 翻译内容 —— YYYY-MM-DD HH:MM [[原推]](链接)
```

⚠️ `>` 是必须的，不能省略。错误示例：
```
翻译内容 —— 2026-06-12 04:51 [[原推]](链接)     ← 错误！缺少 >
```

## 完整模板

```
**🪙 标签名** · N 条新推文

&nbsp;

**@用户A** · N 条

> 推文翻译内容。 —— 2026-06-12 04:51 [[原推]](https://x.com/用户A/status/xxx)

> 推文翻译内容。 —— 2026-06-11 21:25 [[原推]](https://x.com/用户A/status/xxx)

&nbsp;

**@用户B** · N 条

> 推文翻译内容。 —— 2026-06-12 05:08 [[原推]](https://x.com/用户B/status/xxx)
```

## 样式细节

- 标签标题前加一个相关 emoji（如 🪙 黄金圈、👑 影响力、🤖 AI）
- 用户之间用 `&nbsp;` 空行分隔，保持呼吸感
- 如果只有一个标签，省略标签标题，直接展示用户分组

# 总结分析方法论

当用户要求总结推文、分析主题动态时，按以下方法处理。

## 数据获取

1. 拉取最新推文：`~/.hermes/skills/xwatch/scripts/xwatch check [--tag <主题>] --force`
2. 查询缓存推文：`~/.hermes/skills/xwatch/scripts/xwatch tweets [--user X] [--tag <主题>] [--since 7d] --json`
3. 获取账号列表：`~/.hermes/skills/xwatch/scripts/xwatch list [--tag <主题>] --json`

## 翻译规则

- 非中文推文翻译为中文后展示
- 中文推文直接展示原文，无需翻译

## 分组策略

- **多用户时**：按用户分组，每个用户下按时间倒序
- **单用户时**：直接按时间倒序
- **多主题时**：先按主题分区，再按用户分组

## 结构化总结

生成总结时包含以下要素：

- **推文总数和时间范围**
- **主要话题和关键词**
- **重要推文摘要**（附原文链接）
- **关键观点提炼**：从多条推文中归纳出核心论点，而非逐条复述

## 账号列表展示

当用户要求分享某主题的账号时：

```
你订阅的「黄金」主题账号：
1. @screen_name (昵称) — 简介摘要
2. @screen_name (昵称) — 简介摘要
```
